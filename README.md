# 🔎 OSINT HUB

**OSINT HUB** — веб-платформа для работы с инструментами и методами OSINT (Open Source Intelligence), то есть разведки на основе открытых источников.

🌐 **Открыть сайт:** [OSINT HUB](https://volovichvoda-ai.github.io/OSINT_HUB-/)

## О проекте

OSINT HUB — это удобное информационное пространство для поиска, анализа и систематизации данных из открытых источников. Платформа объединяет полезные OSINT-инструменты в одном интерфейсе.

## Возможности

- **База инструментов** — каталог OSINT-ресурсов по различным категориям.
- **Google Dorks** — генератор поисковых запросов для расширенного поиска информации.
- **Анализатор IOC** — инструмент для работы с индикаторами компрометации.
- **Поиск по категориям** — фильтрация инструментов по направлениям OSINT.
- **Журнал сессии** — отображение системных сообщений.
- **Заметки расследования** — сохранение записей в LocalStorage браузера.

## Категории OSINT

- **Search OSINT** — поисковые системы и операторы.
- **Domain OSINT** — анализ доменов, DNS и IP-адресов.
- **SOCMINT** — исследование открытой информации из социальных сетей.
- **GEOINT** — анализ изображений, карт и географических данных.
